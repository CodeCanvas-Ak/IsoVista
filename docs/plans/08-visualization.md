# 08 · Visualization

## 1. 当前基础与目标

当前链路是：后端 `/view/{bug_id}` 使用 pydot 解析 `conflict.dot`，返回节点和边；前端 `BugView.vue` 使用 G6 展示反例并支持展开、下载。`RunView.vue` 使用 ECharts 展示运行与 profile 数据。

近期目标是提升**异常解释和实验展示的可靠性**，不是新增尽可能多的视图：

1. 固定图数据契约，减少后端字符串清洗和前端猜测。
2. 突出反例环、关键事务、边类型及推导上下文。
3. 让运行状态、verdict 和性能图使用同一 artifact 数据。
4. 保留原始 DOT、历史和配置下载，确保展示可回溯。

## 2. 图数据契约

后端负责把 checker 输出转换为带版本的 DTO；前端只消费 DTO，不重复解析 DOT：

```json
{
  "schema_version": 1,
  "nodes": [
    {"id":"1","label":"Txn(id=1)","ops":"...","relate_to":[],"in_cycle":true}
  ],
  "edges": [
    {"id":"e1","source":"1","target":"2","label":"WR(k1)","relate_to":[],"style":"solid","in_cycle":true}
  ],
  "warnings": []
}
```

迁移期间保持现有字段可用。节点或边缺少可选属性时使用明确默认值；影响语义理解的缺失字段进入 `warnings`，不能静默忽略。原始 DOT 继续作为独立下载文件保存。

## 3. 反例视图：近期增强

- 默认聚焦反例环，提供“查看完整图”切换，避免大历史首次加载不可读。
- 图例说明 WR/WW/RW/SO、实线与推导样式；颜色之外同时使用线型或标签，避免只靠颜色区分。
- 节点详情展示事务操作，边详情展示依赖类型和推导来源；展开前后保持当前视口。
- 对 07 的归约结果可比较前后规模，但不需要引入另一套图组件。
- 解析失败、空图和不完整属性显示可诊断错误，不渲染一张空白“成功图”。

自然语言解释只生成有图数据支持的模板句，不推测数据库内部原因。

## 4. 运行与性能视图

- 运行页明确区分排队、执行、完成、取消和失败；`timeout/oom/error` 不混入 accept/reject 统计。
- checker 对比共享 09 的指标定义，图中展示样本数、单位和缺失值。
- 阶段堆叠图只堆叠可比较阶段，未计时的部分单列为 `untracked`，不强制凑成总耗时。
- 图表可下载其底层 CSV/JSON，保证论文数字能回到原始 run。

## 5. 导出

保留并验证现有 PNG、TikZ、DOT 下载能力；结构化图 JSON 作为后续新增导出。导出的图必须带有 checker、隔离级别、run/case ID 和生成时间等最小上下文，避免图片脱离数据来源。

自包含 HTML、布局分享和动画不是当前必要条件。

## 6. 可选扩展

SQL 表状态、谓词命中和时间线视图只有在 04 能提供对应数据后实现。phantom 场景至少需要两次谓词读的返回行集和观测完整性；缺少这些字段时不生成貌似精确的表状态回放。

自定义热加载脚本 hook 涉及安全与维护成本，当前不纳入计划；优先提供固定的过滤、聚焦和展开操作。

## 7. 验收

- `dgraph_si` 用例可展示反例环、展开推导并下载原始数据，新旧迁移前后节点和边语义一致。
- 缺失属性、非法 DOT 和后端解析失败均有可见错误，不导致整个页面崩溃。
- 大图采用默认聚焦或分层加载，并用明确样例记录渲染规模与实际耗时，不预设脱离环境的阈值。
- 运行页每个数字都能定位到 run manifest 和原始指标文件。
- SQL 数据未接入前，不出现不可用的 SQL 视图入口。
